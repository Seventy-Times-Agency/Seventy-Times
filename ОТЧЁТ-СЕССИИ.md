# Отчёт сессии · переработка seventy-times.com

Выполнены задачи 1–11 из TASK.md. Сборка и линт зелёные, 58 статических
страниц, три локали (en / ru / uk) без дыр — TypeScript проверяет состав
словарей на компиляции. История — 11 коммитов, по задаче на коммит.

## Что сделано

1. **Немецкий удалён.** Локали en/ru/uk. Старые `/de/*` URL отдают 301 → `/en/*`.
2. **Hero и CTA.** «Обсудить проект» + «Как мы работаем» (якорь на процесс),
   "See the packages" удалена. Формула-заголовок не тронута.
3. **Пакеты снесены.** GrowthMachine и все `gm*` строки удалены. На месте —
   секция «Как мы начинаем» (брифинг 20 мин → диагностика при необходимости →
   план и цифры), стиль Process, без цен. В Process добавлен этап «Аудит»
   (Брифинг → Аудит → Стратегия → Запуск → Оптимизация) по документу 12 §4.2.
4. **Гарантии заменены политикой документа 2** во всех местах (FAQ, terms,
   hero-подзаголовок, кольца hero): сроки-цепочки от получения материалов,
   разграничение вины историей задач, частичный возврат/скидка по ситуации.
   Слова «guarantee» в маркетинговом смысле на сайте нет.
5. **Услуги** — 4 карточки на месте, из описаний убран порог «$500+/мес».
6. **Vanessa.** Новый системный промпт: квалификация по 6 вопросам (ниша, гео,
   сайт/реклама, бюджет-вилка, срочность, ЛПР) → передача в отдел продаж.
   Цен не называет, воронку не навязывает, форматы описывает по запросу.
   Фото заменено иллюстрацией (`public/vanessa-avatar.png`), подпись
   «AI consultant» на виду. Поле package в форме/чате → интерес к услуге
   (реклама / сайт / бот / одна услуга), LAUNCH/GROWTH/SCALE удалены.
7. **Кейсы.** kids-fashion удалён (страница отдаёт 404). Перевозки — честно:
   Украина 2020–2021, 7–10 заявок/день при ~$200/мес, 9 месяцев; блок выручки
   и продаж клиента удалён. Буковель — описательно, без единой цифры, с
   пометкой «довоенный рынок Украины». Полка: автоковрики (флагман) → Convioo →
   Seventy Times → отдельная группа «Ранний опыт 2020–2021» (визуально
   отделена, на мобильных скрыта). В elitecarmats.ts — закомментированный
   каркас рекламного блока с TODO под реальные цифры и скрины.
8. **Команда.** Запись основателя активна (имя «Maksym» — подтвердить полное
   публичное написание). Записи руководителей продаж и операционки написаны
   полностью (роли + био en/ru/uk), но закомментированы до подтверждения
   публичных имён — мы не публикуем выдуманных людей. Раскомментировать +
   вписать имя = готово. Фото: TODO `/public/team/*.jpg`.
9. **FAQ.** «Прайс индивидуально после брифинга» — на месте. Пункты про
   возвраты и «скидку за комплекс» заменены политикой сроков.
10. **Посадочные `/go/audit` и `/go/brief`.** Вне навигации и sitemap,
    noindex. Весь оффер (заголовки, буллеты, $100, CTA, FAQ) — в одном файле
    `src/data/offers.ts`. $100 существует только там. Лид с посадочной
    получает метку `landing=audit|brief` (через lib/utm.ts, first-touch) и
    она долетает до Telegram/Notion/email в строке источника.
11. **Мобильная диета** (десктоп не тронут, контент не удалён — только CSS/
    условный рендер): hero — 2 кольца вместо 4; кейсы — горизонтальная лента
    из 3 карточек со snap-скроллом; сравнение — аккордеон по критериям;
    ROI-симулятор свёрнут до кнопки; FAQ — 5 вопросов + «Показать все».

## Что осталось владельцу / следующим сессиям

- **Шаг 0 / задача 12 (деплой).** Не выполнялись: у сессии не было доступа к
  GitLab компании, а подключённый Vercel — личный hobby-аккаунт, что нарушает
  правило «всё на аккаунтах компании». Порядок прежний: репозиторий → GitLab
  компании → новый Vercel-проект компании → env по `.env.example` (все ключи
  перевыпустить, старые отозвать) → превью → DNS → старый деплой удалить.
- Подтвердить публичные имена команды (team.ts, TODO-метки) + фото.
- Данные рекламы автоковриков (elitecarmats.ts, закомментированный каркас).
- Кейс Seventy Times расширить после визуального прохода владельца.
- Офферные тексты посадочных при запуске рекламы правятся только в
  `src/data/offers.ts`.

Примечание по сборке в песочнице: Google Fonts здесь недоступен, поэтому
локальная проверка шла с `NEXT_FONT_GOOGLE_MOCKED_RESPONSES`. На Vercel это
не нужно — шрифт тянется штатно.
